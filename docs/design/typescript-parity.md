# TypeScript gateway parity contract

This is the contract for `ts/` against the post-[ADR 0063](../adr/0063-stateful-only-namespaced-gateway.md) Rust gateway. [ADR 0066](../adr/0066-typescript-hono-extension-contract.md) records the decisions. The conformance launcher is `ops/typescript-compat.sh`.

## Same wire

| Behavior | Evidence |
| --- | --- |
| `GET /healthz` is `200` `ok`. `GET /readyz` is `ready`, or `503` `draining` as soon as SIGTERM starts shutdown. New `/api` and `/ns` requests stay admitted for `shutdown.drain_grace_ms`. Admission then closes and a request still accepted is `503` `draining` with `Retry-After: 0` before authentication. | CLI |
| Exactly one `[[gateway_key]]`. `Authorization: Bearer` wins over `x-api-key`. Missing or wrong key is `401` `unauthorized` before namespace lookup. | compat lanes |
| Inference is `/ns/{ns}/v1/...`. The raw path is checked before percent-decoding, so `/ns/%70latform/...` is `400` `invalid_namespace` and the identifier is not echoed. The ADR 0062 `/namespaces/{ns}` spelling is unmounted, including when the identifier is percent-encoded. | compat lanes |
| Unknown namespace is `404` `unknown_namespace`. Unprefixed model is `400` `model_unprefixed`. A non-boolean `stream`, a `previous_response_id` that is not a string or null, and `stream: true` on embeddings are `400` `bad_request` before the provider is called. The message does not echo the value. `malformed_responses_controls_never_reach_the_provider` covers that refusal. | compat lanes |
| OpenAI chat, embeddings, and Responses, buffered and streamed. Anthropic Messages, including thinking and tool-use bytes. Model rewritten to the bare id. A Messages request always sends `anthropic-version`: the caller's value wins, including an empty one, and an omitted header uses `2023-06-01`. `anthropic-beta` is sent only when the caller set it. Other routes do not copy those headers or `Accept`. `messages_wire_headers_default_the_version_and_keep_the_caller_pin` covers that. An OpenAI chat stream sets the last top-level `stream_options.include_usage` to true and replaces a non-object `stream_options`. Responses and Messages do not. Duplicate keys, field order, and integers above 2^53 stay in the bytes sent upstream and in a buffered provider body returned to the caller. Provider credential injected. Gateway key stripped. `chat_stream_forces_include_usage_and_keeps_other_bytes` covers the splice. | `tests/compat`, `tests/compat-ts`, gateway tests |
| Streamed fixtures in `tests/fixtures/**/*.sse` are relayed byte-for-byte, including across chunk splits. A fast fixture does not gain a `: keepalive` comment. An open stream with no terminal event emits `: keepalive` 15s after the last chunk and does not append `upstream_stream_error`. A streamed response sets `content-type: text/event-stream` and `cache-control: no-cache`. | gateway streaming tests |
| No budget row, or `spent >= limit`, is `429` `budget_exceeded`. A failed budget read is `503` `budget_unavailable` unless `[storage] on_unavailable = "allow"`, which serves the request and does not charge. Other Store failures are `503` `store_unavailable`. The driver message is not returned. Charge is one usage row per `request_id`. Delete bumps incarnation so a late settle does not charge. | store tests |
| File namespaces do not inherit platform credentials unless `allow_platform_fallback`. API-created namespaces do. Config namespaces cannot be deleted (`409`). | gateway |
| A provider `429` rotates to the next credential in the pool and counts toward `credential_pool.failure_threshold` (default 2). A `500` stays on that credential and does not park it. An OpenAI chat stream that sends a rate-limit event before any content rotates the same way and does not forward that event. A rate-limit event after content stays on that stream and counts as one credential failure, so the stream end does not clear the streak. A rate-limit event after the terminal frame does not. Responses and native Messages do not rotate on a mid-stream rate-limit event; that event counts as one credential failure. After `cooldown_seconds` (default 30) the status is `probe` and one request is allowed through; handing out that probe rearms the cooldown. A success clears the streak. Responses stay pinned to the first credential. `0` for the threshold or cooldown fails boot. | gateway |
| Management routes and the OpenAPI 3.1 document match `ops/check-openapi.py`. | `ts/openapi.json` |
| Withdrawn config sections fail boot by name and do not echo secret values. `transport.max_response_bytes` and `admission.max_request_bytes` load from the file; `0` is rejected. An oversized body is `413` `request_too_large` and is not echoed. `transport.max_error_bytes` (default 65536) truncates a provider error body; the provider status still reaches the caller. `0`, or a value above `max_response_bytes`, fails boot. `admission.max_prompt_tokens` (default `1000000`) and `admission.max_output_tokens` (default `200000`) load from the file; `0` disables that ceiling. Estimated input over the prompt ceiling is `413` `prompt_too_large`. A requested output allowance over the output ceiling is `400` `output_limit_exceeded`. Neither message echoes the request. | config tests |
| A per-request spend cap above the pre-dispatch estimate is `403` `request_cost_ceiling_exceeded` before the provider is called. The estimate is the JSON byte length divided by four, plus the requested output allowance or 1024. Embeddings estimate no output. An equal estimate is served, and settlement charges measured usage. The usage event names `credential_source`, `credential_id`, `latency_ms`, and `attempts` (`1` for the single target, including after credential rotation). An inbound trace id is kept; a missing one is omitted. A provider failure after a credential is selected records one usage event with status `upstream_error`, zero token counts, and cost 0, and does not increase spent. A client cancel records `client_cancelled` and charges the prompt estimate plus one token per four relayed characters when the provider has not reported usage. An open stream that goes idle appends an SSE `upstream_stream_error` on the already-`200` response and records `upstream_error` for the text already relayed. `admission.max_stream_duration_ms` (default `3600000`) and `admission.max_stream_bytes` (default `67108864`) load from the file; `0` disables that bound. A stream that outlives the duration before a terminal event, or whose next chunk would pass the byte cap, stays `200` and appends an SSE `upstream_stream_error` naming that bound. The overflowing chunk is not forwarded. Text already relayed is charged as `upstream_error`. After a terminal event the duration bound closes the body as `ok` and does not record `axond.upstream.timeouts`. | gateway |
| `GET /ns/{ns}/v1/credentials` reads the raw query. A repeated `namespaces` parameter, or a component that is not percent-encoded UTF-8, is `400` `bad_request`. `%61ll` is `all`. `+` is a space. An empty or other value is `400`. Unknown keys are ignored. Rows are sorted by namespace, provider, and credential id. `source` is `platform` or `byok`. A fallback tenant sees platform pools it does not override, and an env-derived platform label is omitted. | gateway |
| `failover.overall_timeout_ms` (default 30000) tightens the header and buffered-body waits. A budget already spent before the next credential is opened is `504` `upstream_timeout`. An open stream is not cut by that budget. After a terminal SSE event, `transport.stream_terminal_grace_ms` (default 1000) closes the body and returns the stream admission slot while the provider socket is still open; bytes that arrive inside the grace are relayed. A transport error after `response.completed`, `message_stop`, or chat `[DONE]` leaves the body as the bytes already relayed and settles `ok`. An incomplete tail after any of those terminal events is relayed through EOF and settles `ok`. `transport.connect_timeout_ms` (default 5000) is enforced on Node. `0` fails boot. `failover.max_attempts` (default 3) caps target attempts. This process has one configured target, so a cap of 1 still walks every credential on a `429`. Responses still uses one target. `0` and a non-integer fail boot. | gateway |
| A buffered success records `axond.request.time_to_first_token` across the credential walk. A stream records it when the first provider byte is released, and records `axond.upstream.time_to_first_token` when the first SSE data event is decoded, from the attempt that opened the stream. A held rate-limit frame counts for the upstream histogram and does not count for the request histogram. Status `upstream_error` increments `axond.upstream.errors`. A client cancel does not. | gateway |
| SQLite and Postgres record `axond.store.acquire_wait`, `axond.store.query_duration`, and `axond.store.operations` (`ok` or `error`) for each catalogue store operation. A failed Postgres connect records the wait and `error`, and records neither a query duration nor an opened session. A successful Postgres call counts one `axond.store.connections_opened` and one `axond.store.connections_discarded`. Labels are the backend and the operation. The namespace, the SQL, and the driver text are not labels. Extension migrations apply once on SQLite and on Postgres. `postgres_extension_migration_applies_once_and_omits_the_driver_text` runs a non-idempotent `CREATE TABLE` twice, records one id, and a failed statement names that id without the driver text or the DSN. | store tests |
| A `models-dev` catalogue fetch records `axond.catalog.refusals` with reason `unreachable`, `denied`, `unsupported_endpoint`, `not_json`, or `not_retained`. `axond.catalog.consecutive_refusals` is stored in `axond_catalog_streak` and climbs across store objects on the same database. It returns to 0 when an import is stored. `axond.catalog.active_age` is recorded after a stored import and stays absent before the first one. The source URL and the error text are not labels. | discovery tests |
| `admission.max_in_flight` (default 1024) and `admission.max_in_flight_streams` (default 512) shed before the provider is called. A full request ceiling is `503` `gateway_overloaded`. A stream with no slot is `503` `stream_capacity_exhausted`. Both send `Retry-After: 1`. `0` disables that ceiling. An omitted stream ceiling follows a lowered `max_in_flight`. The queue is off unless `queue_capacity` and `queue_wait_ms` are set together; a full queue is `503` `admission_queue_full` and an expired wait is `503` `admission_queue_timeout`. `max_pending_settlements` defaults to four times `max_in_flight`. A replica already carrying that many unsettled charges is `503` `settlement_capacity_exhausted`. An unauthenticated request does not take a slot. `max_in_flight_settlements` defaults to 64. A charge waits `settlement_queue_wait_ms` (default 10000; `0` waits without a bound) for an execution slot. A wait that expires drops the charge, records `axond.settlement.failures` with reason `queue_timeout`, and does not write spend. `settlement_timeout_ms` (default 10000; `0` disables) records reason `execution_timeout` when the Store call outlives the deadline and still finishes the charge. `axond.settlement.oldest_pending_age` is the age in milliseconds of the oldest spawned charge and returns to 0 when none are outstanding. An admitted request counts as `axond.settlement.in_flight` stage `reserved` until that charge is spawned. Shutdown waits up to half of `shutdown.flush_timeout_ms` for those charges. Any still outstanding increment `axond.shutdown.abandoned_settlements`. The lifecycle gauge `axond.shutdown.phase` is 1 while draining and 2 once admission closes. Requests still open at `shutdown.deadline_ms` increment `axond.shutdown.abandoned_requests`. | gateway |

## Gaps, on purpose

| Rust behavior | TypeScript |
| --- | --- |
| Per-replica tenant admission and `tenant_concurrency_exceeded` | Not in core. Use the rate-limit extension. |
| Alias failover across providers | Absent, as in ADR 0063. Credential rotation within one provider retries `provider_dependency_failed` on the next pool member. Responses stay pinned to the first credential. |
| Minted tokens, revocation, redaction | Extensions (`@axond/tokens`, `@axond/redact`). Core still rejects an `axt1.` credential that no extension accepts. |
| Billing-grade usage journal (ADR 0049) | Not built. The usage insert is the charge key. |
| Redis budget backend | Not an SDK dependency. |
| Hot reload of config, including the `axond.revision.converge` span | Withdrawn. Extensions load at process start. |
| OTLP/HTTP protobuf traces, metrics, and usage logs | OTLP/HTTP JSON traces and metrics when `OTEL_EXPORTER_OTLP_ENDPOINT` is set. `grpc` and `http/protobuf` fail boot. Request logs are one JSON object on stdout and omit prompts, completions, and credentials. Each upstream attempt has an `axond.credential.lease` child: `served`, `rate_limited`, `error`, or `parked`, with parked credentials numbered before the ones that were called. A buffered success records `axond.ttft_ms` equal to that attempt's latency, and the server span carries the same usage, cost, and credential source as the charge. A provider refusal records attempt `axond.status` as `error` with OpenTelemetry error status, `axond.upstream.status` as the provider code, and `axond.upstream.message` with the credential replaced by `[REDACTED]`. The caller-visible type stays on the HTTP body. `provider_refusals_keep_their_class_and_export_bounded_attempt_diagnostics` covers buffered and streamed chat, Responses, and Messages. The caller body does the same. `provider_error_replaces_the_echoed_credential` covers that body. The message keeps the provider text through 4096 bytes. A longer one ends with `… [truncated]` on the caller body, and the attempt span keeps that prefix without the marker. Context-limit wording (`context_length_exceeded`, `context length`, `context window`, `prompt is too long`, `prompt too long`, `maximum number of tokens`, `too many tokens`, `maximum prompt length`) is `context_window_exceeded` before the status class, including a top-level `message`. A `401` or `403` with that wording stays HTTP 502. `provider_diagnostics_keep_context_limits_and_a_bounded_message` covers that classification and bound. `attempt_span_records_a_header_timeout` records `axond.timeout` `response_headers` and bound `phase`. `credential_lease_spans_follow_the_pool_walk` covers a 429 rotation and the next request's parked skip. The stdout request log carries the server-span fields known when the handler returns: subject, target, credential source, and, for a buffered charge, status, retry count, token counts, cost, latency, and time to first token. A stream log records the route and leaves usage off that line. `request_log_carries_server_span_fields_and_omits_content` keeps the prompt, the completion, and both secrets out of that object. A rate-limit rotation logs `credential_rate_limited` with the credential id. An upstream timeout logs the phase and bound. A stream that outlives its duration logs `stream_limit`. A catalogue import logs `admitted` or `refused` with the bounded reason. A refused connect logs `upstream_transport` with reason `refused` and omits the address. A stream reset before a terminal event logs phase `stream`. A reset after chat `[DONE]` logs phase `closing` and still settles `ok`. A chunk past the byte cap logs `stream_limit` with limit `bytes`. Those lines omit the secret, the prompt, and the source URL. `credential_rate_limit_log_names_the_id_and_omits_the_secret`, `upstream_timeout_log_names_the_phase_and_omits_the_address`, `stream_limit_log_names_the_duration_cap`, `catalogue_import_log_names_the_reason_and_omits_the_url`, `upstream_transport_log_names_the_reason_and_omits_the_address`, `open_stream_transport_log_names_the_phase_and_omits_the_address`, `stream_byte_limit_log_names_the_size_cap`, `transport_failure_reason_is_a_bounded_class`, and `settlement_failure_log_names_the_reason_and_omits_the_prompt` cover them. A charge that misses the execution queue logs `settlement_failure` with reason `queue_timeout`. A charge that outlives its execution deadline logs `execution_timeout` and still writes the row. The line names the wait and omits the prompt. A charging route whose budget read fails logs `budget_unavailable` with stance `deny` or `allow`. `budget_store_log_names_the_stance_and_omits_the_driver_text` covers that line. Deny answers `503` and does not call the provider. Allow serves the request and does not charge. The line omits the driver text, the prompt, and the secret. A models read that hits the same outage stays `store_unavailable` and does not write that budget line. A Store write that throws during settlement logs `settlement_failure` with reason `charge_failed` and does not write spend. `charge_failure_log_names_the_reason_and_omits_the_driver_text` covers that line. The caller still receives the provider response. The line omits the driver text, the prompt, and the secret. The CLI writes JSON `msg` `shutdown` for `requested`, `second_signal`, `admission_closed`, `signal_ignored`, and `deadline_expired`. The line names the signal and the phase and omits the bind address, the store path, and the gateway key. `shutdown_log_names_the_phase_and_omits_the_secret` covers that line. A byte-faithful body that stays open after its terminal event logs `terminal_remain` with bound `grace` or `duration` and still settles `ok`. `terminal_remain_log_names_the_bound_and_omits_the_secret` covers that line. A clean EOF after the terminal event does not write it. The line omits the endpoint, the prompt, and the secret. When the settle share ends with a spawned charge or an admitted request still open, the process writes JSON `msg` `shutdown` with `phase` `spend_unsettled`, the stage counts, and `oldest_settlement_ms`. `shutdown_spend_log_names_the_stages_and_omits_the_secret` covers that line. A drain that finishes both counts does not write it. The line omits the bind address, the store path, the prompt, and the secret. A file-backed gateway key keeps its bytes, including a trailing newline, and the usage subject is the env name or the file path. A group- or other-readable key file logs `key_material` with that path. `file_gateway_key_keeps_exact_bytes` and `key_material_log_names_the_path_and_omits_the_secret` cover those lines. The file bytes stay off the log. A failed provider `/models` refresh writes JSON `msg` `provider_discovery` with the provider id and reason `no_credential`, `unreachable`, `denied`, `not_json`, or `not_retained`. `provider_discovery_log_names_the_provider_and_omits_the_secret` covers that line. The credential, the base URL, and the driver text stay off it. A refresh walks every credential in the platform pool, or in the lexicographically first tenant pool, and follows `has_more` for up to 20 pages. A later round leaves a fresh row from another base URL untouched. `provider_listing_walks_the_pool_and_omits_the_secret` covers that walk, and a listing that is still paging on page 20 logs reason `page_bound` without the credential or the base URL. A catalogue or provider `3xx` is not followed. `catalogue_and_listing_redirects_are_not_followed_and_omit_the_secret` and `upstream_redirect_is_not_followed_and_omits_the_secret` cover that refusal. The credential stays on the configured URL and the refusal omits `Location`. |
| Separate connect timeout on the Bun binary and on Workers | The header and failover budgets still bound the attempt. Node applies `connect_timeout_ms` with its HTTP client. |
| Postgres session pool (`axond.store.connections_reused`, `axond.store.pool.sessions`) and a separate usage-index append (`usage_append`) | Each Postgres call opens one client and closes it. The usage row and the spend update are one `budget_charge`. Extension `query` is not a catalogue operation. |
| Target circuit gauge `axond.upstream.circuit_state` | Not recorded. Credential parking is the pool circuit. Target breakers stay out of core. |
| Catalogue schema refusals (`schema`, `price`, `content`, and the rest of that vocabulary) | This importer stores a JSON document it could parse. It does not apply the models.dev schema. The refusal streak is a TypeScript table, not the Rust catalogue holder. |

## Distribution

| Target | How |
| --- | --- |
| Node process | `ts/bin/axond` |
| Container | `ts/Dockerfile`. The repository-root `Dockerfile` remains the Rust release image. |
| Worker | `ts/packages/worker`. Hyperdrive caching disabled. Not executed against PlanetScale here. |
| Compiled binary | `bun build --compile` of `ts/packages/cli/src/main.ts`, when Bun is installed. CI runs the unit suite on Bun and the compat lanes through the Node wrapper. |

## Shadow

`ts/scripts/shadow-compare.ts` sends the fixture suite through the Rust binary and `ts/bin/axond`. Status, parsed JSON, and the charged `(model, status, cost)` rows match. Rust re-encodes some JSON objects with sorted keys. TypeScript relays the upstream bytes, which is what the streaming fixtures require. Each process mints its own `request_id`.
