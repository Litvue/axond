# TypeScript gateway parity contract

This is the contract for `ts/` against the post-[ADR 0063](../adr/0063-stateful-only-namespaced-gateway.md) Rust gateway. [ADR 0066](../adr/0066-typescript-hono-extension-contract.md) records the decisions. The conformance launcher is `ops/typescript-compat.sh`.

## Same wire

| Behavior | Evidence |
| --- | --- |
| `GET /healthz` is `200` `ok`. `GET /readyz` is `ready`, or `503` `draining` as soon as SIGTERM starts shutdown. New `/api` and `/ns` requests stay admitted for `shutdown.drain_grace_ms`. Admission then closes and a request still accepted is `503` `draining` with `Retry-After: 0` before authentication. | CLI |
| Exactly one `[[gateway_key]]`. `Authorization: Bearer` wins over `x-api-key`. Missing or wrong key is `401` `unauthorized` before namespace lookup. | compat lanes |
| Inference is `/ns/{ns}/v1/...`. The raw path is checked before percent-decoding, so `/ns/%70latform/...` is `400` `invalid_namespace` and the identifier is not echoed. The ADR 0062 `/namespaces/{ns}` spelling is unmounted, including when the identifier is percent-encoded. | compat lanes |
| Unknown namespace is `404` `unknown_namespace`. Unprefixed model is `400` `model_unprefixed`. A model with an empty provider segment is `400` `unknown_provider` and the message is `unknown provider \`\``. A model whose id after the first `/` is empty is `400` `bad_request` with message `model id after \`/\` must not be empty`. `empty_model_segments_match_the_rust_split` covers that. A JSON `null`, array, or other non-object is `400` `bad_request` with message `missing \`model\``. Bytes that are not JSON are `400` `bad_request` with message `request body is not valid JSON`. Neither call reaches the provider. `json_null_is_missing_model_and_invalid_json_names_the_body` covers that. A content type is JSON when it parses as `application/json` or `application/*+json`, including a charset parameter. `text/json`, `application/jsonfoo`, and a value that only contains the substring `application/json` are `415` `unsupported_media_type`. The same check applies to a management body. `json_content_type_matches_axum` covers that. A non-boolean `stream`, a `previous_response_id` that is not a string or null, and `stream: true` on embeddings are `400` `bad_request` before the provider is called. The message does not echo the value. `malformed_responses_controls_never_reach_the_provider` covers that refusal. | compat lanes |
| OpenAI chat, embeddings, and Responses, buffered and streamed. Anthropic Messages, including thinking and tool-use bytes. Model rewritten to the bare id. A Messages request always sends `anthropic-version`: the caller's value wins, including an empty one, and an omitted header uses `2023-06-01`. `anthropic-beta` is sent only when the caller set it. Other routes do not copy those headers or `Accept`. `messages_wire_headers_default_the_version_and_keep_the_caller_pin` covers that. A native Messages stream keeps the provider bytes. An event that breaks the sequence appends `upstream_stream_error` whose message is `provider stream was invalid: …`, and the charge is `upstream_error`. A provider `error` event uses that provider message, or `Anthropic stream error` when it has none, and a rate-limit event uses `provider stream was rate limited: …` without rotating. Provider text in those messages is cut at 4096 bytes. After a complete `message_stop` that check stops, so a later incomplete tail stays on the wire and settles `ok`. `native_messages_sequence_ends_an_invalid_stream` covers the refusal. Usage on that stream follows `merge_anthropic_usage`: `message_start` and `message_delta` each replace a counter when its key is present, including a zero. A `message_delta` therefore keeps `reasoning_tokens`, `input_tokens`, and the cache counters, and a later zero replaces the value from `message_start`. `native_messages_usage_folds_message_delta_counters` covers that. A Responses stream keeps the provider bytes. A `response.completed` without status `completed`, a missing `data.type`, an event name that disagrees with `data.type`, or a `[DONE]` that carries an event name appends `upstream_stream_error` with `provider stream was invalid: …` and charges `upstream_error`. A rate-limit event uses `provider stream was rate limited: …` and does not rotate. A data-only `[DONE]` or a completed response ends that check. `responses_sequence_ends_an_invalid_stream` covers the refusal. An OpenAI chat stream sets the last top-level `stream_options.include_usage` to true and replaces a non-object `stream_options`. Responses and Messages do not. Duplicate keys, field order, and integers above 2^53 stay in the bytes sent upstream and in a buffered provider body returned to the caller. Provider credential injected. Gateway key stripped. `chat_stream_forces_include_usage_and_keeps_other_bytes` covers the splice. | `tests/compat`, `tests/compat-ts`, gateway tests |
| Streamed fixtures in `tests/fixtures/**/*.sse` are relayed byte-for-byte, including across chunk splits. A fast fixture does not gain a `: keepalive` comment. An open stream with no terminal event emits `: keepalive` 15s after the last chunk and does not append `upstream_stream_error`. A streamed response sets `content-type: text/event-stream` and `cache-control: no-cache`. | gateway streaming tests |
| No budget row, or `spent >= limit`, is `429` `budget_exceeded`. A failed budget read is `503` `budget_unavailable` unless `[storage] on_unavailable = "allow"`, which serves the request and does not charge. Other Store failures are `503` `store_unavailable`. The driver message is not returned. Charge is one usage row per `request_id`. Delete bumps incarnation so a late settle does not charge. | store tests |
| File namespaces do not inherit platform credentials unless `allow_platform_fallback`. API-created namespaces do. Config namespaces cannot be deleted (`409`). Creating or replacing a namespace measures `attrs` and the blocklist as UTF-8 JSON bytes. Attrs over 4096 bytes are `400` `bad_request` with message `attrs exceeds 4096 byte limit`. A blocklist over 64 entries is refused for that count, and one whose JSON exceeds 4096 bytes is refused as over 4 KiB, before a glob is checked. A glob that is not an exact id, `prefix*`, `*suffix`, or `*` is `400` `bad_request` and names that pattern. `namespace_attrs_and_blocklist_match_the_rust_limits` covers that. Creating a namespace refuses an empty id, an id over 128 UTF-8 bytes, a character outside ASCII letters, digits, `.`, `-`, and `_`, and an id that does not start and end with a letter or digit. Each refusal is `400` `bad_request` with the Rust message, and the id stays out of that message. A byte length over 128 is reported before the character check. A management path looks the segment up as given: a missing id is `404` `unknown_namespace` on read and `204` on delete. An inference path still answers `400` `invalid_namespace` with `namespace identifier is invalid`. `namespace_create_uses_the_rust_identifier_messages` covers that. A `[[namespace]]` id those rules refuse stays in the loaded config and is not inserted. Seeding the same file again leaves the valid row in place. `config_seed_skips_invalid_namespace_ids` covers that. An unknown field on a namespace or budget write is `400` `bad_request` and names that field the way serde does, including the line and column. A missing `id`, a limit that is a string or a float, a cadence other than `monthly` or `fixed`, and a limit above the signed 64-bit store range are refused the same way. A limit of `9223372036854775807` is stored. `management_json_rejects_unknown_fields_and_out_of_range_limits` covers that. A list `limit` that is not a `u32`, and a repeated `limit`, `cursor`, or usage `period`, is `400` `bad_request` with the serde query message. `0` and a value above 1000 stay `` `limit` must be between 1 and 1000 ``. `management_query_matches_the_rust_deserializer` covers that. A management body that is not an object uses the serde type or syntax message, including a positional JSON array. `attrs: null` is stored as `{}`. A JSON number, string, boolean, or array is stored as that value. `management_json_matches_serde_syntax_and_null_attrs` covers that. A repeated management field is refused as `duplicate field` before the second value is read. The column is the one serde reports after the object tail: whitespace is consumed, a closing `}` is consumed, and any other byte stays. A duplicate key inside `attrs` is stored, with the later value kept. `management_json_rejects_duplicate_fields` covers that. A management string reports `invalid escape`, `control character (\u0000-\u001F) found while parsing a string`, `lone leading surrogate in hex escape`, `unexpected end of hex escape`, or `EOF while parsing a string`, and the column counts UTF-8 bytes. A bad escape inside `attrs` or a blocklist entry names that path. A map where a string or integer is required stays an invalid type. `management_json_string_escapes_match_serde` covers that. A cadence is the string `monthly` or `fixed`, or the unit-enum object `{"monthly":null}` or `{"fixed":null}`. An unknown variant names that key and leaves its value unread. A unit value that is not null is `invalid type: …, expected unit` on `cadence.<variant>`. A second key is `expected value`. `management_json_cadence_unit_enum_matches_serde` covers that. A byte sequence that is not UTF-8 inside a management string is `invalid unicode code point` at the closing quote. A bad byte outside a string stays a structural error, and a type mismatch leaves the interior unread. `management_json_invalid_utf8_matches_serde` covers that. A stored attrs value is reserialized the way serde_json does: object keys are sorted, an integer that fits in `i64` or `u64` keeps every digit, and a float uses serde's finite format, including `1.0` and `-0.0`. `management_json_attrs_match_serde_reserialization` covers that. A byte after a complete management value is `trailing characters` at that byte, including the first byte of a multi-byte scalar. `management_json_trailing_characters_match_serde` covers that. A usage summary groups by model and status in UTF-8 byte order. A null cost adds nothing, a repeated request id counts once, and a total past the signed 64-bit cap stays that cap, with every digit. `usage_summary_matches_the_rust_grouping` covers that. A monthly period is the civil `YYYY-MM` in the IANA 2026c database the Rust gateway bundles. `Africa/Casablanca` at `2026-09-30T23:00:00Z` is `2026-09`. `Factory`, `America/Coyhaique`, and `Etc/Unknown` are accepted. `PST` is refused. `monthly_period_matches_the_bundled_tzdb` covers that. A budget ledger and a budget policy write `limit_microdollars`, `spent_microdollars`, `reserved_microdollars`, and `remaining_microdollars` as JSON numbers. `9223372036854775807` keeps every digit. `budget_amounts_match_serde_numbers` covers that. A monthly policy reports the clock's `YYYY-MM` and, when that period has a ledger row, that row's limit and spend. `PUT …/budgets/{period}` on another key leaves the policy on the clock period, and `active` on a monthly ledger follows the clock. `cadence` `fixed` without `period` re-limits the active period. With none, it is `400` `bad_request` and the message is `fixed cadence needs a period: the namespace has no active period`. A namespace with only a ledger returns that row as `fixed` and `timezone` `UTC`. `budget_policy_follows_the_cadence_period` covers that. | gateway |
| A provider `429` rotates to the next credential in the pool and counts toward `credential_pool.failure_threshold` (default 2). A `500` stays on that credential and does not park it. An OpenAI chat stream that sends a rate-limit event before any content rotates the same way and does not forward that event. When no later credential can take that stream, including a pool of one, those bytes stay on the wire and the stream appends `upstream_stream_error` whose message is `provider stream was rate limited: …`, charges `upstream_error`, and counts as one credential failure. `a chat rate limit before content on one credential fails the stream` and `a chat rate limit with no credential left fails the stream` cover that. A rate-limit event after content stays on that stream, appends `upstream_stream_error` whose message is `provider stream was rate limited: …` (the provider `/error/message`, or `OpenAI stream rate limited`), charges `upstream_error`, and counts as one credential failure, so the stream end does not clear the streak. The provider bytes stay on the wire. `a rate limit after chat content stays on that stream` covers that. A rate-limit event after the terminal frame is relayed and does not append that error or park the credential. Responses and native Messages do not rotate on a mid-stream rate-limit event; that event counts as one credential failure. After `cooldown_seconds` (default 30) the status is `probe` and one request is allowed through; handing out that probe rearms the cooldown. A success clears the streak. Responses stay pinned to the first credential. `0` for the threshold or cooldown fails boot. | gateway |
| Management routes and the OpenAPI 3.1 document match `ops/check-openapi.py`. | `ts/openapi.json` |
| Withdrawn config sections fail boot by name and do not echo secret values. `transport.max_response_bytes` and `admission.max_request_bytes` load from the file; `0` is rejected. An oversized body is `413` `request_too_large` and is not echoed. `transport.max_error_bytes` (default 65536) truncates a provider error body; the provider status still reaches the caller. `0`, or a value above `max_response_bytes`, fails boot. `admission.max_prompt_tokens` (default `1000000`) and `admission.max_output_tokens` (default `200000`) load from the file; `0` disables that ceiling. Estimated input over the prompt ceiling is `413` `prompt_too_large`. A requested output allowance over the output ceiling is `400` `output_limit_exceeded`. Neither message echoes the request. | config tests |
| A per-request spend cap above the pre-dispatch estimate is `403` `request_cost_ceiling_exceeded` before the provider is called. The estimate is the JSON byte length divided by four, plus the requested output allowance or 1024. Embeddings estimate no output. An equal estimate is served, and settlement charges measured usage. The usage event names `credential_source`, `credential_id`, `latency_ms`, and `attempts` (`1` for the single target, including after credential rotation). An inbound trace id is kept; a missing one is omitted. A provider failure after a credential is selected records one usage event with status `upstream_error`, zero token counts, and cost 0, and does not increase spent. A client cancel records `client_cancelled` and charges the prompt estimate plus one token per four relayed characters when the provider has not reported usage. An open stream that goes idle appends an SSE `upstream_stream_error` on the already-`200` response and records `upstream_error` for the text already relayed. `admission.max_stream_duration_ms` (default `3600000`) and `admission.max_stream_bytes` (default `67108864`) load from the file; `0` disables that bound. A stream that outlives the duration before a terminal event, or whose next chunk would pass the byte cap, stays `200` and appends an SSE `upstream_stream_error` naming that bound. The overflowing chunk is not forwarded. Text already relayed is charged as `upstream_error`. After a terminal event the duration bound closes the body as `ok` and does not record `axond.upstream.timeouts`. | gateway |
| `GET /ns/{ns}/v1/credentials` reads the raw query. A repeated `namespaces` parameter, or a component that is not percent-encoded UTF-8, is `400` `bad_request`. `%61ll` is `all`. `+` is a space. An empty or other value is `400`. Unknown keys are ignored. Rows are sorted by namespace, provider, and credential id. `source` is `platform` or `byok`. A fallback tenant sees platform pools it does not override, and an env-derived platform label is omitted. | gateway |
| `failover.overall_timeout_ms` (default 30000) tightens the header and buffered-body waits. A budget already spent before the next credential is opened is `504` `upstream_timeout`. An open stream is not cut by that budget. After a terminal SSE event, `transport.stream_terminal_grace_ms` (default 1000) closes the body and returns the stream admission slot while the provider socket is still open; bytes that arrive inside the grace are relayed. A transport error after `response.completed`, `message_stop`, or chat `[DONE]` leaves the body as the bytes already relayed and settles `ok`. An incomplete tail after any of those terminal events is relayed through EOF and settles `ok`. A chat stream that ends before `[DONE]` with a partial SSE event appends `stream ended with an incomplete SSE event`. A stream that ends inside a UTF-8 character appends `stream ended mid-character`. Both charge `upstream_error` and keep the provider bytes. `chat_eof_names_an_incomplete_event_and_a_split_character` covers that. An SSE buffer that would pass 1048576 bytes before a terminal event appends `SSE buffer exceeded 1048576 bytes`, charges `upstream_error`, and keeps the bytes that crossed the limit. Complete events that stay under that cap can total more, and bytes after a terminal event are not measured. `sse_buffer_limit_fails_an_unterminated_event_and_keeps_a_finished_stream` covers that. An OpenAI chat `data:` event that is not JSON and is not `[DONE]` appends `provider stream was invalid: …`, charges `upstream_error`, and keeps the provider bytes. The pool does not rotate and the credential stays healthy. A `[DONE]` ends that check, so a later non-JSON tail is relayed and settles `ok`. A block with no `data:` line is left alone. `chat_invalid_json_fails_the_stream_and_keeps_the_credential` covers that. `transport.connect_timeout_ms` (default 5000) is enforced on Node. `0` fails boot. `failover.max_attempts` (default 3) caps target attempts. This process has one configured target, so a cap of 1 still walks every credential on a `429`. Responses still uses one target. `0` and a non-integer fail boot. | gateway |

A stream records it when the first provider byte is released, and records `axond.upstream.time_to_first_token` when the first SSE data event is decoded, from the attempt that opened the stream. A held rate-limit frame counts for the upstream histogram and does not count for the request histogram. Status `upstream_error` increments `axond.upstream.errors`. A client cancel does not. | gateway |

| `admission.max_in_flight` (default 1024) and `admission.max_in_flight_streams` (default 512) shed before the provider is called. A full request ceiling is `503` `gateway_overloaded`. Requests still open at `shutdown.deadline_ms` increment `axond.shutdown.abandoned_requests`. | gateway |

## Gaps, on purpose

| Rust behavior | TypeScript |
| --- | --- |
| Per-replica tenant admission and `tenant_concurrency_exceeded` | Not in core. Use the rate-limit extension. |
| Alias failover across providers | Absent, as in ADR 0063. Credential rotation within one provider retries `provider_dependency_failed` on the next pool member. Responses stay pinned to the first credential. |
| Minted tokens, revocation, redaction | Extensions (`@axond/tokens`, `@axond/redact`). Core still rejects an `axt1.` credential that no extension accepts. |
| Billing-grade usage journal (ADR 0049) | Not built. The usage insert is the charge key. |
| Redis budget backend | Not an SDK dependency. |
| Hot reload of config, including the `axond.revision.converge` span | Withdrawn. Extensions load at process start. |
| OTLP/HTTP protobuf traces, metrics, and usage logs | OTLP/HTTP JSON traces and metrics when `OTEL_EXPORTER_OTLP_ENDPOINT` is set. `grpc` and `http/protobuf` fail boot. Request logs are one JSON object on stdout and omit prompts, completions, and credentials. Each upstream attempt has an `axond.credential.lease` child: `served`, `rate_limited`, `error`, or `parked`, with parked credentials numbered before the ones that were called. A buffered success records `axond.ttft_ms` equal to that attempt's latency, and the server span carries the same usage, cost, and credential source as the charge. A provider refusal records attempt `axond.status` as `error` with OpenTelemetry error status, `axond.upstream.status` as the provider code, and `axond.upstream.message` with the credential replaced by `[REDACTED]`. The caller body does the same. `provider_error_replaces_the_echoed_credential` covers that body. The message keeps the provider text through 4096 bytes. A longer one ends with `… [truncated]` on the caller body, and the attempt span keeps that prefix without the marker. Context-limit wording (`context_length_exceeded`, `context length`, `context window`, `prompt is too long`, `prompt too long`, `maximum number of tokens`, `too many tokens`, `maximum prompt length`) is `context_window_exceeded` before the status class, including a top-level `message`. A stream log records the route and leaves usage off that line. `request_log_carries_server_span_fields_and_omits_content` keeps the prompt, the completion, and both secrets out of that object. A rate-limit rotation logs `credential_rate_limited` with the credential id. An upstream timeout logs the phase and bound. A stream that outlives its duration logs `stream_limit`. A catalogue import logs `admitted` or `refused` with the bounded reason. A refused connect logs `upstream_transport` with reason `refused` and omits the address. Those lines omit the secret, the prompt, and the source URL. `credential_rate_limit_log_names_the_id_and_omits_the_secret`, `upstream_timeout_log_names_the_phase_and_omits_the_address`, `stream_limit_log_names_the_duration_cap`, `catalogue_import_log_names_the_reason_and_omits_the_url`, `upstream_transport_log_names_the_reason_and_omits_the_address`, `open_stream_transport_log_names_the_phase_and_omits_the_address`, `stream_byte_limit_log_names_the_size_cap`, `transport_failure_reason_is_a_bounded_class`, and `settlement_failure_log_names_the_reason_and_omits_the_prompt` cover them. The line names the wait and omits the prompt. A charging route whose budget read fails logs `budget_unavailable` with stance `deny` or `allow`. `budget_store_log_names_the_stance_and_omits_the_driver_text` covers that line. Deny answers `503` and does not call the provider. Allow serves the request and does not charge. The line omits the driver text, the prompt, and the secret. A models read that hits the same outage stays `store_unavailable` and does not write that budget line. A Store write that throws during settlement logs `settlement_failure` with reason `charge_failed` and does not write spend. `charge_failure_log_names_the_reason_and_omits_the_driver_text` covers that line. The caller still receives the provider response. The line omits the driver text, the prompt, and the secret. The credential stays on the configured URL and the refusal omits `Location`. |
| Separate connect timeout on the Bun binary and on Workers | The header and failover budgets still bound the attempt. Node applies `connect_timeout_ms` with its HTTP client. |
| Postgres session pool (`axond.store.connections_reused`, `axond.store.pool.sessions`) and a separate usage-index append (`usage_append`) | Each Postgres call opens one client and closes it. The usage row and the spend update are one `budget_charge`. Extension `query` is not a catalogue operation. |
| Target circuit gauge `axond.upstream.circuit_state` | Not recorded. Credential parking is the pool circuit. Target breakers stay out of core. |
| Catalogue schema refusals (`schema`, `price`, `content`, and the rest of that vocabulary) | This importer stores a JSON document it could parse. It does not apply the models.dev schema. The refusal streak is a TypeScript table, not the Rust catalogue holder. |

## Shadow

`ts/scripts/shadow-compare.ts` sends the fixture suite through the Rust binary and `ts/bin/axond`. Status, parsed JSON, and the charged `(model, status, cost)` rows match. Rust re-encodes some JSON objects with sorted keys. TypeScript relays the upstream bytes, which is what the streaming fixtures require. Each process mints its own `request_id`.
